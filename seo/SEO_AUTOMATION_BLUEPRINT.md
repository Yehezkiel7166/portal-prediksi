## Safety

- Manual overrides tetap authoritative.
- Auto-publish wajib diaktifkan eksplisit.
- Semua perubahan memiliki history.
- Generated value menyimpan source dan version.
- Rollback wajib tersedia.
- Cannibalization wajib dideteksi.
- SERP provider menggunakan replaceable contract.
- Current SERP claim membutuhkan snapshot terbaru.
