# Sprint 19A-2 — Site Configuration Filament Administration

## Objective

Provide safe administrator editing of the current brand's single Site Configuration record.

## Scope

- brand-isolated resource query;
- singleton create availability;
- validated identity, SEO, contact, social, and footer form;
- persistence through `UpsertSiteConfiguration`;
- admin access and isolation tests;
- no schema migration.

## Excluded

Frontend consumption, analytics identifiers, Open Graph expansion, and JSON-LD remain later increments.
