# Keyword Intelligence

Version: 1.0

Status: Canonical

---

# Purpose

This document defines the Keyword Intelligence strategy for Portal
Prediksi CMS.

Keyword Intelligence provides a structured framework for discovering,
organizing, evaluating, and maintaining keywords throughout the entire
content lifecycle.

Rather than treating keywords as isolated search terms, the platform
treats them as interconnected assets linked to entities, brands,
content, search intent, and user needs.

This strategy supports scalable SEO planning, content architecture,
semantic search optimization, and long-term organic growth.

---

# Objectives

The Keyword Intelligence strategy aims to:

- organize keywords consistently;
- improve topical authority;
- support semantic SEO;
- strengthen internal linking;
- reduce keyword duplication;
- improve search intent coverage;
- support future automation.

---

# Core Principles

Every keyword should:

- have a permanent identifier;
- belong to one or more topics;
- have a defined search intent;
- support one or more entities;
- connect to relevant content;
- remain traceable throughout its lifecycle.

---

# Keyword Categories

## Branded

Keywords directly associated with an official brand.

Examples:

- brand name
- brand variations
- branded services

---

## Non-Branded

General keywords not tied to a specific brand.

Examples:

- football prediction
- match analysis
- betting tips

---

## Entity Keywords

Keywords representing entities.

Examples:

- organization
- player
- team
- competition

---

## Transactional

Keywords indicating action.

Examples:

- register
- join
- login
- buy

---

## Informational

Keywords indicating learning intent.

Examples:

- guide
- tutorial
- explanation
- comparison

---

## Navigational

Keywords used to locate a specific destination.

Examples:

- official website
- homepage
- dashboard

---

## Commercial

Keywords indicating evaluation before action.

Examples:

- review
- comparison
- alternatives
- best

---

# Search Intent

Every keyword should belong to one or more intent groups.

Primary intents include:

- Informational
- Navigational
- Commercial
- Transactional

Intent classification should remain stable across the platform.

# Platform Responsibilities

The CMS should eventually support:

- keyword grouping;
- topic clustering;
- entity mapping;
- search intent classification;
- duplicate detection;
- keyword-to-content relationships;
- reporting and monitoring.

---

# Governance Rules

Every primary keyword should have one canonical owner.

Duplicate keyword targeting should be avoided.

Keyword relationships should remain consistent with entity
relationships.

Keyword planning should support long-term content architecture rather
than isolated page optimization.
