# Architecture Decision Records

This directory is the canonical index of Architecture Decision Records (ADRs). ADR identifiers are unique and sequential. Historical decisions are preserved; superseded decisions must be marked in their document rather than deleted or renumbered again.

## ADR Rules

- Select the next unused sequential number from this index.
- Use one ADR for one durable architectural decision.
- Update internal references and this index in the same commit.
- Preserve accepted and superseded ADR history.
- Record status, context, decision, consequences, and date where available.
